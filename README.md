# 🐍 Calculadora com IA — Aprendizado Interativo de Python

Um projeto educacional desenvolvido com apoio de Inteligência Artificial para tornar o aprendizado de Python mais visual, prático e acessível para quem está começando a programar.

A ideia começou com uma calculadora simples, capaz de realizar as quatro operações matemáticas básicas, e evoluiu para uma experiência interativa que explora conceitos fundamentais da linguagem Python.

🔗 **Repositório:** [github.com/LucasDevRJ/calculadora_com_ia](https://github.com/LucasDevRJ/calculadora_com_ia)

## 🎯 Objetivo do projeto

O objetivo é demonstrar como a Inteligência Artificial pode auxiliar no desenvolvimento de software e na criação de ferramentas educacionais, combinando exemplos de código, experimentação prática e recursos para fixação do conhecimento.

Mais do que calcular resultados, o projeto busca ajudar iniciantes a entender como o código funciona e como resolver problemas comuns durante a programação.

## ✨ Funcionalidades

### 🧮 Calculadora interativa

- Realização de operações matemáticas.
- Exemplos de operadores aritméticos do Python.
- Interface visual para experimentar cálculos.

### 💻 Visualizador de código

- Exemplos de código Python com diferentes abordagens.
- Explicações sobre os principais componentes da linguagem.
- Exemplos que demonstram o uso de condicionais, funções, repetições e tratamento de erros.

### 🖥️ Simulador de terminal

Um ambiente interativo para acompanhar a execução dos exemplos e entender como o programa recebe entradas e apresenta resultados.

### 🐛 Laboratório de debugging

Exemplos de erros comuns durante o desenvolvimento, incluindo:

- `ValueError`
- `ZeroDivisionError`
- `IndentationError`
- `TypeError`
- `SyntaxError`

A proposta é facilitar a compreensão dos erros e mostrar como identificá-los e corrigi-los.

### ⚙️ Gerador de código personalizado

Possibilidade de explorar diferentes recursos da linguagem e montar exemplos de código com funcionalidades selecionadas, como:

- Operações matemáticas adicionais.
- Estruturas de repetição.
- Funções.
- Histórico de cálculos.
- Tratamento de erros.
- Arredondamento de resultados.

### 🧠 Quiz e guia de referência

- Perguntas para revisar os conceitos estudados.
- Referência rápida de operadores, tipos de dados, comparações e funções do Python.
- Exemplos para consulta durante os estudos.

## 🛠️ Tecnologias e ferramentas

- **Python:** linguagem utilizada na implementação da calculadora e nos exemplos de programação.
- **Google AI Studio:** ferramenta utilizada como apoio no desenvolvimento com Inteligência Artificial.

A interface interativa reúne recursos voltados à experimentação e ao aprendizado dos conceitos apresentados.

## 📚 Conceitos explorados

O projeto permite estudar e experimentar conceitos fundamentais de Python, como:

- Variáveis e tipos de dados.
- Entrada e saída de informações.
- Conversão de tipos.
- Estruturas condicionais (`if`, `elif` e `else`).
- Estruturas de repetição.
- Funções.
- Listas e histórico de cálculos.
- Operadores aritméticos.
- Tratamento de exceções.
- Identificação e correção de erros.

## 🚀 Como explorar o projeto

1. Acesse o [repositório no GitHub](https://github.com/LucasDevRJ/calculadora_com_ia).
2. Explore os arquivos disponíveis e identifique os exemplos de código Python.
3. Experimente os recursos interativos disponibilizados pelo projeto, caso estejam incluídos na versão acessível.
4. Execute e modifique os exemplos localmente para observar como as alterações afetam o comportamento do programa.

Para executar o código Python localmente, é necessário ter o Python instalado e utilizar o arquivo correspondente à calculadora disponível no repositório.
